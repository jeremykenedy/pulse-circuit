# Pulse Circuit 1.0.0

First public release of the original Pulse Circuit geometric screensaver.

- Adds a continuously animated geometric arena with drifting polygon forms, particle pulses, and orbiting rings.
- Adds settings for arena, shape density and geometry, motion, neon palette, pulse rhythm, light intensity, per-setting random choices, and randomize-all.
- Uses a bright, many-shapes default while keeping every option adjustable or randomizable.
- Adds a guided ADB installer, update path, and confirmed uninstall flow.
- Targets Android API 23 and later at the app package level. Vendor-specific TV behavior remains subject to the device verification matrix.
- Runs offline. The standalone installer downloads the signed release APK and checksum from GitHub when run.

Upgrade from an earlier version by installing the signed APK from the release. The package ID and signing key remain stable across updates. No migration is needed for this first release.
